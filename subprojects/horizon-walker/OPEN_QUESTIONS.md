# Horizon Walker 2024 open questions and roadmap

1. Test damaging Emanations with level-13/15 reaction teleportation and record extra exposures, target geometry and resource spending.
2. Test early levels on planes with few portals and short fights; measure whether planar investigation/movement supplies useful identity.
3. Test one/two/three/five-target Distant Strike scenarios and legal many-attack builds using the complete turn caps.
4. Compare two-fight and six-fight days with differing rests; Mark, steps, phasing and concentration protection draw on the specified resources.
5. Run investigation scenes involving dormant thresholds, sealed containers, traces, barriers, concealment and mundane decoys. Check clue usefulness without revealing the whole mystery.
6. Revalidate relevant current official spell/errata wording before using the theoretical results for a new balance decision. The old source-access claim is bounded.

Use the existing report section 10 matrix and acceptance criteria. The roughly 15% comparison trigger there is a proposed project triage rule, not an official ceiling or automatically adopted universal standard.
