# Hearth & Hazard

A broader modular fantasy rules project using a recognizable 2024 d20 chassis, with older-D&D, Pathfinder and Shadowdark influences. The emphasis is understandable world interaction, meaningful exploration/social play, environmental consequences and consistent adjudication.

The recovered foundation is a 97-page July 2026 DOCX, converted to [foundation draft v0.1](versions/foundation-draft-v0.1.md) for search and version control. The original remains in Drive. Its “Core Rule” labels define the document's proposed default; they are not evidence of user adoption.

This is a distinct game-system draft. It is not the Shadowdark campaign and does not automatically inherit Shadowdark's later class or exploration decisions.
