# Build and rules research

This small workstream preserves visible research briefs that are useful to the DnD Homebrew project but are not original subclass releases. Full prior answers/selection histories were not recovered. Keep unrelated build or adventure decisions independent of the homebrew designs.

It contains Rune Knight skill-build planning, Ranger-spell and rules questions, and a high-level dungeon search brief. The current task archives these directions; it does not invent research findings or choose a build/adventure.
