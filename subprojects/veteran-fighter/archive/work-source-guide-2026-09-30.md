# Veteran Work / Deep Research — Source Guide

## Best setup

If possible, start **Work from the existing DnD Homebrew project** and run Deep Research there. The project already contains the important Veteran chats and files, so duplicating them as uploads is normally unnecessary.

Use the revised prompt in `Veteran_Work_Deep_Research_Prompt.md`.

## Important project sources

Ask the task to review these existing project sources:

1. `VETERAN FIGHTER SUBCLASS — MASTER PROJECT HANDOFF.md`
2. `PROJECT EVOLUTION TIMELINE.md`
3. `Veteran Fighter Subclass: Design, Balance, and Optimization Research Report`
4. `Veteran.md` / Iteration D.4.1
5. the chats `Homebrew Veteran Fighter Subclass` and `Veteran Fighter Subclass Design`
6. `Veteran_Current_State_Addendum_2026-09-30.md` if you add it to the project

## If using a standalone Work chat instead of the project

Upload, in priority order:

1. Master Project Handoff
2. Current-State Addendum
3. Project Evolution Timeline
4. Prior Design/Balance/Optimization Research Report
5. Veteran.md / D.4.1
6. exports/transcripts of the two Veteran chats, if available

The full old chat transcript is useful for provenance and abandoned ideas but is lower priority than the handoff, timeline, research report, and current-state addendum.

Avoid uploading duplicate copies such as `(1)` versions when the contents are identical.
