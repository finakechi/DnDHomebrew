# Shadowdark homebrew linked project

This work has its own [repository](https://github.com/finakechi/Shadowdark) and [Drive folder](https://drive.google.com/drive/folders/19hf4wYi1d-LLnxmdxMFX8Raba0P_Cqii). They remain authoritative; this folder is a dated navigation/handoff record.

It develops a short underground campaign with familiar character identities, more features/magic, reduced exploration bookkeeping and consequential danger. The latest twelve-class work is in [open PR #1](https://github.com/finakechi/Shadowdark/pull/1), separate from main. Re-read its current state before continuing.
