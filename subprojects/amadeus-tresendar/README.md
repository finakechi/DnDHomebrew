# Amadeus Tresendar

Recovered one-off monster work: “Amadeus Tresendar, the Runebound Loup Garou,” associated with a Curse of Strahd character. The source character sheet is available; the complete generated monster stat block was not recovered.

This record preserves the design brief and source distinction so future work does not fabricate a replacement stat block from memory or mistake a player character sheet for a monster release.
