# DnDHomebrew
Various DnD Homebrew ideas.

This workspace preserves Noah's designs, alternatives and development history. Begin with [PROJECT_INDEX.md](PROJECT_INDEX.md), then read the relevant subproject's STATUS.md before continuing work.

- [Project status](PROJECT_STATUS.md) — active work and next steps.
- [Governance](GOVERNANCE.md) — authority, approval and version rules.
- [ChatGPT Project Instructions](CHATGPT_PROJECT_INSTRUCTIONS.md) — copy the complete file into the project's Instructions field.
- [Audit](audit/AUDIT_REPORT.md), [source inventory](audit/SOURCE_INVENTORY.md), [conflicts](audit/CONFLICT_REGISTER.md), and [verification](audit/VERIFICATION_REPORT.md).
- [Drive assets](https://drive.google.com/drive/folders/1Aq4LsIz2po3W6dUfvVPRXLHL4koADgbK).

Most recovered designs are working or proposed. A polished report, a “recommended” label, or a later upload does not establish approval. Preserved source documents retain their historical wording; current STATUS and DECISIONS records define their scope.
