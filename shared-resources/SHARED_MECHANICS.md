# Shared mechanics and interaction map

No shared homebrew mechanics are adopted by this organizational audit. This map identifies topics requiring consistent review while preserving distinct implementations.

| Topic | Projects | Dependency or review question |
|---|---|---|
| Unarmed/improvised attacks | Veteran; Bartitsu | Veteran contact does not inherit implement benefits; Bartitsu's Finesse/weapon exception has its own unresolved wording. Never copy one override into the other by assumption. |
| Grapple/Shove | Veteran; Bartitsu | Distinguish damage options, saving-throw DCs, free hands, size and later escape checks under the chosen edition. |
| Reactions and off-turn offense | Veteran; Bartitsu; Amadeus | Model competing defensive reactions and actual trigger availability; Amadeus's final package is missing. |
| Movement and action compression | Veteran; Horizon Walker | Distinguish ordinary attack slots, granted attacks, Procedures, teleport limits and resource spending. |
| Exploration, light and urgency | Hearth & Hazard; Shadowdark | Similar goals, distinct baselines. Shadowdark's immediate darkness constraint does not approve Hearth's draft 10-minute procedure. |
| Existing class integration | Horizon Walker; Shadowdark | Horizon 0.2 explicitly proposes Ranger replacements at 13/17/20; Shadowdark adapts class identities without importing whole D&D kits. |
| Environmental permissions | Veteran; Hearth & Hazard | FET's bounded physical procedure is not a license for a complete environment subsystem. |

Sources: the current design, history and audit links in [PROJECT_INDEX.md](../PROJECT_INDEX.md). Possible future transfers belong in [AI_OBSERVATIONS.md](../AI_OBSERVATIONS.md), pending separate design decisions.
