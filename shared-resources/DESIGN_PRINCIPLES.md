# Shared design principles

These are source-backed recurring goals and editing practices, not a new universal mechanics package. A subproject's explicit brief governs when goals differ.

| Principle | Evidence and scope |
|---|---|
| Preserve recognizable class identity | Veteran current-state report; Bartitsu design report; Horizon Walker redesign brief |
| Make useful choices available before late levels | Veteran feedback and experiment brief; Horizon Walker early movement objective |
| Count complete action/resource interactions | Veteran/Bartitsu audits; Horizon Walker 0.2; Shadowdark complete-kit evaluation |
| Support exploration and practical problem solving | Veteran Field-Expedient Tool; Horizon planar investigation; Hearth & Hazard foundation |
| Prefer clear, bounded permissions | Veteran Procedure boundaries and failed broad replacement engine; Hearth wording standards |
| Keep quantitative conclusions conditional | Both subclass audits and Horizon report explicitly distinguish modeled cases from table evidence |

Do not universalize mundane-only design: it is central to Veteran/Bartitsu, while Horizon Walker is planar magic and Shadowdark explicitly seeks more magic. Do not make Shadowdark's twelve-class roster or light procedure the default for Hearth & Hazard or ordinary 2024 D&D.

Read each [project handoff](../PROJECT_INDEX.md) before applying these themes.
